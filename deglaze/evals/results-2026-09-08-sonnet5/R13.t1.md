Cache "the quote" per customer and two calls for the same customer with different cart totals or a different region inside the same 5-minute window return whichever price got cached first. That's not an edge case — subtotal changes on nearly every call, so this fires constantly, not occasionally.

A blind 5-minute TTL doesn't react to a tier change — it just waits it out. A customer who upgrades mid-window pays the old, higher price for up to 5 minutes; one who downgrades keeps a discount they no longer qualify for. If tier changes are the one event you claim matters, the cache should invalidate on that event, not on a clock that ignores it.
